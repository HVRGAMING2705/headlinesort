HeadlineSort

AI news headline classifier, by Vikranth Reddy

What is this headline about?

Paste a news headline. HeadlineSort vectorizes it with TF-IDF (word unigrams, sublinear TF, L2 norm, 914-feature vocabulary) and a Multinomial Naive Bayes model — trained on 200 hand-written headlines — outputs predict_proba for the 5 classes, all in your browser. No backend, no API calls.

The JS demo reproduces sklearn's probabilities to 1e-15 — it IS the trained model.

How it works

1. Dataset
200 hand-written, realistic headlines: 40 each for sports, technology, business, politics and entertainment.
2. Features
TF-IDF over word unigrams: lowercase, tokens ≥ 2 chars, sublinear TF (1 + log tf), smooth IDF, L2-normalized, top 1000 features (914 in practice).
3. Model
Multinomial Naive Bayes. Joint log-likelihood = class log-prior + tfidf · feature log-probs, then softmax → per-class probabilities.
4. Evaluated
Stratified 5-fold cross-validation: 76.5% accuracy (vs 20.0% random baseline, 3.8×). Train accuracy 100.0%.
